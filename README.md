# Portfolio professionnel - Savin N'Guessan

Refonte d'un portfolio multi-pages pour un ingenieur en mecatronique et robotique.
Le site adopte une presentation plus structuree, une navigation interne plus claire
et une direction visuelle plus professionnelle.

## Structure

- `index.html` : page d'accueil et vue d'ensemble
- `about.html` : profil et competences
- `expertise.html` : expertises, methodologie et domaines d'intervention
- `projects.html` : projets et cas concrets
- `experience.html` : parcours, formation et certifications
- `contact.html` : coordonnees et formulaire de contact
- `styles.css` : charte visuelle globale et responsive
- `script.js` : navigation active, menu mobile, animation d'apparition et formulaire

## Utilisation

1. Ouvrir `index.html` dans un navigateur.
2. Naviguer entre les sous-pages via le menu principal.
3. Sur la page contact, le formulaire ouvre la messagerie par defaut avec un email pre-rempli.

## Notes

- Le site ne depend plus de Bootstrap.
- Les polices et certaines images sont chargees depuis des sources externes.
- Toute la structure repose sur des pages HTML statiques et un style partage unique.
